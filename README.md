# AICS Learning Intelligence Dashboard

An interactive, privacy-first prototype for students to track study momentum, assess topic confidence, and build an explainable study plan.

## Live product

The app runs fully in the browser and uses fictional demo data by default. Add a short reflection to see the learning pulse, priorities, and weekly plan update.

## Features

- Learning readiness score and study streak
- Explainable priority engine
- Topic-level confidence and mastery map
- Weekly plan with completion state
- Browser-local reflections using `localStorage`
- Responsive and accessible interface

## Run locally

Open `dist/index.html` in a browser. No build step or backend is required.
